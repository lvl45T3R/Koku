## دربارهٔ پروژه

کوکو یک ابزار اتصال امن برای اندروید است. این برنامه با الهام از پروژهٔ [ایثر](https://github.com/CluvexStudio/Aether)
ساخته شده و از موتور ارتباطی آن استفاده می‌کند. ظاهر برنامه و بخش‌های ویژهٔ
اندروید برای کوکو نوشته شده‌اند؛ بنابراین پروژه یک بازنویسی کامل و مستقل از
ایثر نیست.

شناسهٔ برنامه در اندروید:

`io.github.lvl45t3r.koku`

## امکانات

- سه روش مختلف برای برقراری اتصال
- نمایش وضعیت و میزان رفت‌وآمد داده
- بررسی نشانی اینترنتی و کشور خروجی
- گزارش فنی اختیاری با امکان آغاز، توقف و رونوشت
- آزمون اتصال از طریق مرورگر

نسخهٔ فعلی برای بیشتر گوشی‌های ۶۴ بیتی جدید ساخته شده است.

## حالت‌های جست‌وجوی درگاه

- حالت **Fast** از جست‌وجوی سریع Turbo استفاده می‌کند و گزینهٔ پیش‌فرض است.
- حالت **Reliable** با قابلیت Ironclad ایثر یک تونل واقعی می‌سازد و پیش از
  انتخاب درگاه، یک درخواست HTTP کامل را از داخل تونل بررسی می‌کند.

پس از قطع شدن ارتباط، برنامه ابتدا همان درگاه سالم قبلی را دوباره بررسی
می‌کند و فقط در صورت از کار افتادن آن، جست‌وجوی کامل را از نو انجام می‌دهد.

در به‌روزرسانی موتور ایثر ۱.۴، گواهی سرورهای MASQUE پین می‌شود، تونل خاموش
WireGuard با بررسی واقعی مسیر داده تشخیص داده می‌شود، پردازه‌های قدیمی هنگام
اتصال دوباره پاک می‌شوند و ظرفیت جست‌وجو و حافظه با توان دستگاه هماهنگ می‌شود.
